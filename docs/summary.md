# 프로젝트 요약 — SECOM 반도체 수율 불량 예측 (결과 중심)

> 실제 반도체 라인 계측 데이터로 수율 불량을 예측하고, **양산 배포 관점**(정확도의 함정·모델
> 노후화·비용 운영·통계적 신뢰도)에서 검증한 결과를 한 곳에 정리한다. 모든 수치는 재현 가능한
> 스크립트(`src/`)의 실측값이다.

## 한 문단 요약 (DMI 관점)

실제 반도체 라인 계측 데이터(SECOM, 1,567런 × 590센서)를 분석하여 **DMI(Defect·Metrology·
Inspection) 관점의 수율 불량 예측 파이프라인**을 Python(pandas·scikit-learn)으로 구축·검증했다.
전체 결측 4.5%(최대 센서 91%)·불량률 6.6%의 극단적 불균형·590차원 데이터를 대상으로,
**중앙값 대치 → 결측 플래그 특성화 → 분산 필터 → 표준화 → 분류기**의 전처리 전 과정을 데이터
누수 차단 파이프라인으로 구성했다. **Mann-Whitney U 검정 + BH-FDR**로 470개 유효 센서 중
불량과 유의한 21개(FDR<0.05)를 선별하고 랜덤포레스트 중요도와 교차 일치시켜 **수율영향 계측
(Metrology) 인자**를 도출했다. 이후 예측 확률을 기반으로 Precision-Recall 곡선·시간순 검증을
해석하고, **PR-AUC·Recall·비용 운영점·부트스트랩 신뢰구간·센서 랭킹 안정성** 등 배포 관점의
지표를 추출했다. 챔피언 모델은 **PR-AUC 0.251(무작위 0.066의 약 3.8배)·ROC-AUC 0.81**,
불량 유출 비용 기준 **총비용 38% 절감** 여지를 기록했으며, 시간순 검증에서 PR-AUC가
**0.21→0.06으로 붕괴**함을 확인해 **공정 드리프트에 따른 모델 재학습 주기의 필요성**을 정량적으로
규명했다.

## 핵심 결과 (실측)

| 항목 | 수치 | 의미 |
|---|---|---|
| 정확도의 함정 | 93.4% | 불량 6.6%라 "전부 합격"만 찍어도 나오는 가짜 성적 |
| PR-AUC (RandomForest) | 0.235 (95% CI 0.14–0.40) | 무작위 기준 0.066의 3.6배 |
| PR-AUC (결측 플래그 반영, 챔피언) | 0.251 | "비었다"를 특성화하니 향상 |
| 모델 노후화 | 0.21 → 0.06 | 시간순 검증 시 붕괴 → 재학습 필요 |
| 비용 최적 운영점 | −38% | 임계값 0.5→0.08, 유출:과검=10:1 |
| XGBoost 튜닝 | 0.147 → 0.243 | GridSearchCV로 +0.097 |
| 센서 랭킹 안정성 | Jaccard 0.03 | 전/후반 상위 20센서 겹침 1개 → 고정 관리 위험 |
| 유의 센서 | 21 / 470 | Mann-Whitney U + FDR<0.05 |

## 분석 과정 (DMI 축 태그)

1. **[Metrology] 결측치 처리** — 평균/중앙값/KNN 실측 비교(모두 오차범위 내) → 강건·재현성으로
   **중앙값** 채택. 결측 자체가 신호인지 검증 → 결측 플래그로 0.235→0.251.
2. **[Metrology] 특성선택** — VarianceThreshold + RandomForest 중요도 + Mann-Whitney U(BH-FDR)
   3경로 교차 → 21개 유의, 다중공선성(r>0.97) 점검.
3. **[Defect] 불균형 처리** — SMOTE vs class_weight 실측 비교 → SMOTE 이득 −0.033으로 기각,
   비용가중 채택.
4. **[Defect] 평가** — 정확도 함정을 PR-AUC로 회피. 부트스트랩 95% 신뢰구간으로 우연/진짜 판정.
5. **[Inspection] 시간축 검증** — 시간순 분할로 드리프트 규명, **p-관리도(SPC)로 OOC(관리상한
   이탈)** 포착.
6. **[Data Fusion] 운영·모델** — 비용 운영점(−38%), XGBoost GridSearchCV 튜닝(0.243).

## 무엇을 알 수 있었나 (7가지)

1. 정확도 93.4%는 무의미 — 실 판별력은 PR-AUC 0.235(무작위의 3.6배).
2. 모델은 시간이 지나면 낡는다 — 시간순 PR-AUC 0.06 → 재학습 주기 필요.
3. 불량은 이벤트성 센서(파티클·누설류)와 가장 관련 — 통계·모델·분포 3각 일치.
4. 상위 센서는 시간에 따라 바뀐다(Jaccard 0.03) — 고정 센서 관리 위험.
5. SMOTE는 만능이 아니다 — 여기선 class_weight가 우세.
6. 최적 운영점은 정확도가 아니라 비용 — 임계값 0.08에서 총비용 38% 절감.
7. 빈 칸(결측)은 잡음이 아니라 신호 — 결측 플래그로 성능 향상(0.235→0.251).
